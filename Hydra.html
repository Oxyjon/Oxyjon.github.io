Overview

2D Heatmap is an engine tool developed over 6 weeks that allows developers to generate telemetry heatmaps of their games.

The tool enables game teams to record gameplay telemetry, which is serialized and saved in JSON format. It features an interactive in-editor frontend that renders traffic, player movement paths, and cluster heatmaps to help designers balance levels and detect player friction.
